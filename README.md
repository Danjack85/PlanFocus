# 计划事件 · PlanFocus（发布页）

本仓库**仅用于「计划事件」应用的内置自动更新**，不放源码 —— 只有 Release 里会附上安装包。

## 应用简介

把"行程计划 → 到点提醒 → 专注计时"串成闭环的 Android 应用：录入一天的计划，
到点响铃/语音/震动提醒，关铃即开始专注计时并记录分心情况。

- 计划管理、重复规则（只响一次 / 每天 / 按星期）、文本批量导入
- 精确到点提醒（一主一备双闹钟 + 定期自愈 + 错过补提醒）
- 提醒方式可选：铃声、语音、震动、**仅震动静音模式**
- 专注计时：暂停/继续、长按结束、可选"退出页面后继续计时"
- 应用使用时长监控、每日上限报警、分心 App 明细
- 通知栏常驻倒计时（大字显示距下一项还有多久）

## 下载安装

到 [Releases](../../releases) 页下载最新的 `PlanFocus-*.apk`，在手机上安装即可
（系统会提示"未知来源"，允许一次）。需要 **Android 8.0 及以上**。

应用内也可以在「设置 → 版本更新」里检查更新，会直接下载并校验签名后引导安装。
