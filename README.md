# 计划事件 · PlanFocus（发布页）

本仓库**仅用于「计划事件」应用的内置自动更新**，不放源码 —— 只有 Release 里会附上安装包。

## 应用简介

把"行程计划 → 到点提醒 → 专注计时"串成闭环的 Android 应用：录入一天的计划，
到点响铃/语音/震动提醒，关铃即开始专注计时并记录分心情况。

- 计划管理、重复规则（只响一次 / 每天 / 按星期）、文本批量导入
- **专注时长可按"多少分钟"或"专注到某时刻"来设**（如 12:15 提醒、专注到 16:45），跨午夜自然支持
- **计时中可随时调整目标**：改成"专注到 16:45"，或"再专注 25 分钟"
- 精确到点提醒（一主一备双闹钟 + 定期自愈 + 错过补提醒）
- 提醒方式可选：铃声、语音、震动、**仅震动静音模式**
- 专注计时：暂停/继续、长按结束、可选"退出页面后继续计时"
- **专注统计**：今天 / 近 7 天 / 近 30 天 / 选某天四种口径；柱状图、环形占比、趋势曲线、
  当天 24 小时时间轴、打卡热力图、计划排行与分心 App 排行；另有小结洞察
- **打卡与目标**：连续打卡天数、每日专注目标（首页与统计页的完成度圆环）
- **界面**：开屏动画、底部导航（计划/统计/设置）、深色模式与纯黑背景、动态取色（Material You）、
  自适应图标（含 Android 13 单色主题图标）
- 应用使用时长监控、每日上限报警、分心 App 明细
- 通知栏常驻倒计时（大字显示距下一项还有多久）
- **手环快应用**：小米 Vela 手表/手环上显示下一项计划与倒计时、到点震动、可在手环上添加计划

## 下载安装

到 [Releases](../../releases) 页下载最新的 `PlanFocus-*.apk`，在手机上安装即可
（系统会提示"未知来源"，允许一次）。需要 **Android 8.0 及以上**。

应用内也可以在「设置 → 版本更新」里检查更新，会直接下载并校验签名后引导安装。

手环端（可选）下载同一个 Release 里的 `PlanFocus-watch-release.rpk`，
用 AstroBox-NG 之类的工具装到手表上；**仅支持小米 Vela 系统手环/手表**，
且需要手机装「小米运动健康」并已完成配对。
